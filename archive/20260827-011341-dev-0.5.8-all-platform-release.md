## Residual risks and exclusions

- Windows Authenticode/file signing is disabled by the existing builder configuration.
- Android uses the existing Debug certificate. This APK is for sideload testing, not store submission.
- No ADB device was connected; installation, cold-start, long-conversation, and real-provider mobile runtime checks were not run in this release turn.
- Linux GUI smokes ran under WSL/headless display infrastructure, not a physical Linux desktop session.
- macOS DMG requires a macOS build host and is not part of the current Windows/Linux/Android six-asset release matrix.

## Rollback

Stop distributing the six `0.5.8` assets and direct users to the previously approved prerelease. Withdraw the GitHub prerelease and remote tag only as an explicit release-management action; deprecate `newmark-agent@0.5.8` on npm instead of assuming an unpublish is available. User workspaces require no data rollback because this release performs no data migration. The existing `release-0.5.4/` directory and unrelated user worktree files remain untouched.
