# dev-0.5.14 image_display final-reply presentation

## Requirement

After `image_display`, the displayed image(s) must be concretely shown in the final Agent reply before the reply text, in presentation order, on PC and Android. The Build tool page continues to keep its original inline/collapsed image evidence.

## Implementation

- `DESKTOP/src/ui/index.html`: adds `workRunDisplayImages`, `workDisplayImageGalleryHtml`, and `appendWorkDisplayImages`. Final assistant messages reuse the same normalized agent image list and insert `.conversation-work-display-images` before `.md-rendered`; `updateMsg` re-applies the gallery after a streamed/final rewrite.
- `TUI/src/render.js`: final assistant summaries retain `示意图` rows before the final text, using the same ordered `runDisplayImages`.
- `android/.../WorkRunProjection.kt`: `displayedImages(events)` sorts by `sequence → timestamp → id` and returns each `image_display` presentation.
- `android/.../ChatScreen.kt`: `ChatItem.Bubble.displayedImages` and `WorkDisplayImagePreviews` render the same ordered gallery before `MarkdownBody`.
- `android/.../NewmarkApp.kt`: local and remote projections attach displayed images to the final assistant bubble.
