# dev-0.5.11 移动端布局修复与全平台 Release

## 本轮修复

- 用户输入图片限定在用户消息列右侧；Agent `image_display` 展示图保持左侧，与各自正文对齐。
- 对话区把输入上方 Goal/Flow/Queue 浮层的实时测量高度纳入 LazyColumn 底部避让；输入区尺寸变化时同步更新，避免用户输入时间线与 Build 内时间线被遮挡。
- Markdown/LaTeX 阅读预览复用对话正文的左右安全边界（24dp 起始、34dp 结束），窄屏不再出格。

## 验证与发布

- Android：聚焦契约与全量 `testDebugUnitTest`、Vital Lint、R8、Release assembly 通过；当前无 ADB 设备，未声明真机视觉验收。
- 六个候选资产从同一 0.5.11 源码构建并逐件核对 SHA-256；Android APK 已更新为本轮最新构建。
- Windows MSI/ZIP、Linux AppImage/deb/ZIP 与 Android APK 将绑定提交 `dev-0.5.11` 并上传 GitHub prerelease；macOS DMG 仍需 macOS 主机原生构建。
- Windows MSI 未做 Authenticode，Android 使用工程 Debug v2 证书；这两项不等同于商店生产签名。
