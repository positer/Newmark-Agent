# dev-0.5.9 移动端紧凑玻璃按钮真实画布修复

时间：2026-08-27 13:00 Asia/Shanghai

## 问题

底层关闭 shape clip 与扩大高光离屏层后，紧凑按钮仍处于按钮等大的 Compose 布局/RenderNode 中。左栏新建本地对话、对话顶栏两个按钮和输入区三个按钮的浮起玻璃外沿仍可能被父画布截断。

## 实施

- 新增 `GlassButtonCanvasOutset = 8.dp` 和共享 `GlassButtonCanvas`。
- 外层透明 Box 真实测量为 `visualSize + 16dp`；按钮本体居中且仍保持 24/28/36dp。
- pointer input、clickable、语义与菜单 anchor 均留在视觉按钮本体，透明安全区不造成误触。
- 顶栏两个目标按钮、输入区三个目标按钮和左栏新增按钮全部迁移。
- 发送按钮的 idle 与运行/停止分支共用 52dp 外层槽，内部跑马边框和按钮仍为 36dp。
