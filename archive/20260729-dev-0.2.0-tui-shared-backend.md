Date: 2026-07-29

## Scope

- Add `Newmark --TUI` as a source, global npm-bin, portable, and packaged entry.
- Bind the invoking folder to the normal Newmark Workspace registry.
- Reuse `~/.Newmark`, Agent, Conversation, Memory Lab, Config, Provider/Model, Automation, Archive, and Update implementations.
- Add Conversation-bound Model and persisted Flow selection.
- Preserve background Conversation work while focus changes.
- Correct light-theme full-canvas rendering and Unicode partitioning.

## Interaction contract

- Workspace roots start collapsed; Enter expands/collapses.
- Up/Down traverse a visible menu level; Left/Right traverse levels and content columns.
- Workspace children are conditional on the last-entered Conversation.
- Enter on a Conversation enters editing immediately.
- Tab returns from editing to Conversation selection and retains the draft.
- Shift+Tab cycles Build, Plan, Goal, and Flow; Flow requires workflow selection.
- Esc requests target-bound graceful stop; the next Esc force-stops the same run.
- T pins/unpins a selected Conversation and follows its ID after reorder.
- Operations remain flat and include Help.
