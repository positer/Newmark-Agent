# dev-0.5.9 移动端固定主题色操作记录

时间：2026-08-27 13:26:08（Asia/Shanghai）

## 用户要求

移动端已不再支持自定义调色，因此不需要调色板。

## 审计结论

- 设置页无颜色选择器、自定义颜色字段或调色板配置入口。
- Provider 配置与持久化层无颜色配置字段。
- 原 `NewmarkPalette` 只承载产品内置亮/暗主题的语义色，直接删除会破坏正常亮暗模式，并不等同于移除自定义调色功能。

## 实施

- `NewmarkPalette` 改名为 `NewmarkThemeColors`。
- `NewmarkDarkPalette` / `NewmarkLightPalette` 改名为固定的 `NewmarkDarkThemeColors` / `NewmarkLightThemeColors`。
- `LocalNewmarkPalette` 改名为 `LocalNewmarkColors`。
- 清理设置页和 Memory Lab 的重复主题 import。
- 新增 `FixedThemeColorsContractTest`，禁止自定义调色入口与字段回归。
- 同步纠正文档中设置页仍保留 MD3 ripple 的过期描述；全应用均无灰色涟漪。
