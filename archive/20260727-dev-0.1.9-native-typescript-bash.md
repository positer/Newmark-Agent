# dev-0.1.9 Native TypeScript Bash and Terminal Runtime

Date: 2026-07-27

## Request

Absorb the open-source TypeScript Bash implementation from just-bash into Newmark's native runtime, improve terminal behavior, and use it for the Agent tool and bottom terminal bar.

## Upstream and license

- Upstream: `https://github.com/vercel-labs/just-bash`
- Reviewed package: `just-bash@3.2.0`
- Reviewed upstream commit during implementation: `1e06ce63c4f4e34b110283f419988b044135f779`
- License: Apache-2.0, copyright 2025 Vercel Inc.
- Integration approach: consume the published package and write Newmark-specific routing/session code; do not vendor or silently relabel upstream source.

## Implementation

- Added a shared `nativeBash.ts` boundary using `Bash`, `ReadWriteFs`, execution limits, cancellation, and AST command collection.
- Native execution is workspace-rooted and symlinks are blocked by default.
- Agent and HTTP one-shot Bash execute native-supported scripts and preflight external commands before host-shell fallback, avoiding partial native execution followed by replay.
- Bottom-bar Bash uses a persistent native session with retained `PWD`; unsupported external commands direct users to a host tab or Agent fallback.
- PowerShell/CMD/pwsh/host Bash tabs use the existing `node-pty` backend instead of redirected child pipes.
- The transcript strips unsupported OSC/CSI sequences while retaining escaped textual output.
- WSL and utility-host single-file bundles omit just-bash through lazy runtime loading and retain host-shell fallback, avoiding ESM/native-codec bundle failures.
