# dev-0.2.0 Conversation tracking

The TUI workspace tree is now driven by the last-entered Conversation rather than a fixed global navigation list. Conversations and Model are always present. Plan, Goal, Subagents, Flow Bar, Flow List, and Flow Task appear only when the focused Conversation owns corresponding content.

Conversation editing uses Enter directly. Tab returns to Conversation selection without deleting the draft. Shift+Tab cycles modes and requires explicit workflow selection before Flow editing. Esc is reserved for target-bound two-stage stopping. Running Conversations keep independent rotating left markers; changing focus does not stop them and background completion cannot replace the foreground snapshot.

T toggles the selected Conversation pin and re-finds the selection by ID after sorting. Help is a flat Operation view documenting the complete active shortcut contract.

Verification passes 38/38 TUI tests, including real Core Flow persistence, and the DESKTOP shared-backend stress covers 18 parallel isolated Conversations plus a GUI-backend/TUI/CLI same-Conversation roundtrip.
