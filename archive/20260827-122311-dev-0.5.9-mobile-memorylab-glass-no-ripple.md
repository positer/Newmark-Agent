# dev-0.5.9 移动端 Memory Lab 玻璃按钮与涟漪边界

时间：2026-08-27 12:23:11 Asia/Shanghai

## 实机问题

用户截图显示浅色 Memory Lab 中“新增 / 重建索引”和“双方 / 清除 / 重置”操作区域会出现 MD3 灰色圆形或矩形涟漪。右边栏也存在相同反馈。灰色遮罩覆盖本来的浅色玻璃底与边缘高光，造成局部发脏、形状叠影，破坏 Newmark 玻璃材质的一致性。

## 修改

- `NewmarkTheme.kt`：非设置页同时提供 `NoVisualIndication` 与 `LocalRippleConfiguration=null`。
- `SettingsScreen.kt`：在页面内部单独恢复平台 indication 与 `RippleConfiguration()`，成为唯一允许 MD3 灰色反馈的区域。
- `RightSidebar.kt`：开栏按钮和通用图标按钮显式 `indication=null`。
- `MemoryLabScreen.kt`：新增 `MemoryLabGlassAction`，统一新增、重建、关系模式、清除和重置的高度、最小宽度、间距、禁用态与玻璃按压边缘；不渲染灰色 ripple。
- `GlobalNoRippleContractTest.kt`：固定主应用无涟漪、设置页例外、右边栏显式无 indication、Memory Lab 使用玻璃操作控件的边界。
