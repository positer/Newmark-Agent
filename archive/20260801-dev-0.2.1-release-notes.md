# Newmark Agent dev-0.2.1

This prerelease unifies the updated GUI/TUI conversation experience and introduces first-class Agent-displayed images.

## Highlights

- Added Agent-callable `image_display` for workspace PNG/JPEG evidence.
- GUI images appear immediately after their tool call and remain ordered at the start of collapsed Build summaries.
- TUI rows show only `[示意图]` until selected, then reveal the vision-derived image title and `Enter 打开`.
- Image Enter opens an isolated viewer titled with the image title; Memory Lab Overview opens a graph-only isolated viewer.
- Added live Memory Lab tag search, current-model display beside the Conversation title, placeholder removal, render coalescing, duplicate-frame suppression, and capped animation cadence.
- Added explicit global/npm `Newmark --GUI`; `Newmark --TUI` remains available.

## Validation

- 30-window image/Memory Lab viewer burst: zero failures, peak 6 concurrent viewers.
- Full Windows and isolated Linux source gates passed.
- Windows MSI/ZIP and Linux AppImage/DEB/unpacked ZIP asset smokes passed.
- Windows MSI 0.2.1.0 installed successfully; `~/.Newmark` configuration hashes were unchanged.
- Linux GUI Bash/sh round trips and relaunch/exit lifecycle passed under Xvfb.

Packages are unsigned development builds. Verify downloaded assets against the SHA-256 table in the repository README.
