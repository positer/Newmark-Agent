# dev-0.5.9 Memory Lab 同义词同步与 PC 写入增量化

时间：2026-08-27 11:05:37 Asia/Shanghai

## 目标

- 让 Android Memory Lab 的界面重建按钮和本地 Agent 工具同步 PC 的同义词/近义词去重整合。
- 审计 PC model-facing 写入工具，减少全量重传压力。

## 实现

- Android `MemoryLabStore.reindex()` 成为 UI 与 Agent 共用入口；移植 PC 已知同义词表、`preferredLanguage` 主标签选择、aliases 保留、组件 tags/tagPaths 规范化，并避免原始 tag map 重新生成已合并的孤立别名节点。
- PC `memory_lab_update` 支持 component patch、contentAppend、oldText/newText、replaceAll 和 expectedUpdatedAt；旧 name/tags/content 创建与全量替换兼容。
- PC `flow_save` 支持 action=upsert/delete 的单组件修改，replace 保留全量兼容。
- PC `linked_plan` 支持 append、old_text/new_text 与 replace_all，继续要求 expected_revision。
- 审计确认 `automation_update`、task、Goal 已按字段/条目更新，普通文件已有 `edit`，不增加重复协议。
