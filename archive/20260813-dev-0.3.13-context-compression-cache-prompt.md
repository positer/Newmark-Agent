# Newmark Agent `dev-0.3.13` — two-tier context compression, cache, and prompt policy

Date: 2026-08-13
Scope: source candidate only; no MSI rebuild, global UAC installation, Git tag, or remote publication.

## User findings addressed

- Build-block compression was too eager/repetitive and collapsed active work toward the long-history target.
- Prompt/cache behavior was unstable because the system prompt re-ranked skills from the latest history and linked-plan content was injected every turn.
- Multi-step work lacked a mandatory compact inline task-management contract in the base prompt.

## Changes

- `DESKTOP/src/core/agent.ts`
  - Adds separate Build-block and long-history pressure accounting.
  - Computes total, long-history, and Build-block token estimates in one transcript pass.
  - Active Build threshold/retention is `70%`; long-history trigger/retention budget is `20%`.
  - `context_history_manage status` reports both token counts, thresholds, retention budgets, and usage percentages.
  - Compression reuse recognizes an existing summary anywhere in retained history instead of checking only message zero.
  - Stable system prompt no longer depends on the latest history text for skill ranking.
  - Full linked-plan Markdown/revision is removed from ordinary system-prompt assembly. The `linked_plan` tool and Plan-mode requirements remain.
  - Base prompt requires a bounded inline checklist with `pending`, `in_progress`, `completed`, and `blocked` states.
- `DESKTOP/src/core/agentKernelRunner.ts`
  - Request-scoped task/bootstrap metadata is injected on the first provider request of a Build and once after compression, not on every provider tool sub-turn.
- `DESKTOP/src/context/services/context-orchestrator.ts`
  - Documents the retained `linked_plan` section as a compatibility slot that remains empty for ordinary requests.
- Regression coverage
  - Verifies the two-tier thresholds and active-tail retention.
  - Verifies prompt stability across history/linked-plan mutations and linked-plan body absence.
  - Verifies the bounded inline task contract and cache-oriented task/bootstrap behavior.
