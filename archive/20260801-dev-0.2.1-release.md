# dev-0.2.1 release record

Date: 2026-08-01; refreshed 2026-08-02

## Delivered behavior

- TUI opens directly on Conversation, shows the resolved model beside its title, supports Memory Lab `/` tag search, and removes Overview/Rindex/detail placeholder surfaces.
- `image_display` stores PNG/JPEG evidence once, embeds it immediately after the GUI tool call, and keeps ordered images at the beginning of collapsed Build summaries.
- Unfocused TUI image rows render only `[示意图]`; the selected row expands to its vision-derived image title plus `Enter 打开`.
- Enter opens an isolated image viewer whose native/document/header title is the image title. Memory Lab Overview opens an isolated graph-only viewer that executes the exact GUI graph builder, Anchor/root topology, renderer, physics, camera, focus, drag, zoom, reset, and styles from `dist/ui/index.html`.
- `Newmark --GUI` explicitly starts the GUI from installed and npm launchers; `Newmark --TUI` remains the terminal entry.
- Browser Use uses adaptive DOM-stability waiting and main-content-first extraction informed by official Crawl4AI commit `7e801521428ee12509994d39151006f64055ebe3`, without accepting caller scripts or exposing selectors.
- Model validation exposes eleven determinate check slots per model and a bilingual polled progress bar.
- Guide/Next persists as a user-level setting even when the active workspace contains an obsolete `Guide` override.
- TUI Model and GUI Models share the standard `low` / `medium` / `high` / `xhigh` / `max` intelligence selector; the chosen tier persists and reaches Chat Completions or Responses reasoning fields.
