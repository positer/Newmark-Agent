# dev-0.5.9 玻璃画布布局回归纠正

时间：2026-08-27 15:00 Asia/Shanghai

## 错误

上一轮把 8dp 光学外沿直接加入紧凑按钮的父布局尺寸，导致输入区的 28/36dp 按钮槽实际变为 44/52dp，并改变输入框厚度、间距和呈现。这超出了“只解决绘制截断”的授权范围，也破坏了用户已经定稿的视觉设计。

## 纠正

- `GlassButtonCanvas` 对父级仍只报告 `visualSize`。
- 大画布改为居中的 `requiredSize(visualSize + 16dp)` 绘制子层，不参与 Row/Box 测量。
- clickable、语义及命中范围固定在原始尺寸父节点。
- 输入区恢复 32dp `+` 槽、36dp 模型槽、36dp 发送/停止按钮、既有 padding、Spacer 和中心补偿。
- 左栏新建按钮恢复原有 `padding(end = 10.dp)`。

## 验证

Android 203 项 JVM 测试、Vital Lint、R8、Release assembly 全部通过。新增契约拒绝 `InputComposerEdgeControlSize + GlassButtonCanvasOutset * 2` 出现在输入区布局代码中。
