## Release reliability findings

- The Codex desktop host held a generated `default_app.asar` under the shared workspace, so electron-builder could not atomically rename its unpack directory. The release scripts now accept one optional `NEWMARK_RELEASE_OUTPUT_DIR`, leaving the default CI path unchanged while allowing all platform assets to share an external candidate root.
- The first alternate-root CLI smoke selected the old default unpacked executable. `dist-portable.cjs` now binds `NEWMARK_TEST_EXE` to the candidate `unpackedExe` and a source assertion prevents regression.
- A no-space external Windows candidate path lost backslashes through the WSL argv bridge. `dist-linux.cjs` now passes forward-slash Windows paths to `wslpath`; the focused verifier locks this boundary.
