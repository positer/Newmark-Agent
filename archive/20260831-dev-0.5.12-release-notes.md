# Newmark Agent dev-0.5.12

本预发布包含 Windows、Linux 与 Android 六个安装/便携资产。

## 主要修复

- 移动端与宽布局移除右侧栏折叠态展开按钮，统一由右缘左滑展开。
- 新建本地对话默认使用 Chat 模式。
- Chat 复用既有 `terminal_exec`，执行层仅允许 `date`、`time`、`now` 获取本地时间，不新增工具或写权限。
- 移动端模式/模型选择弹窗圆角与内部玻璃浮块统一为 26dp。
- 修复移动端 Markdown 围栏代码块、LaTeX 可读渲染与压缩后连续图片输入。
- PC Markdown 代码块支持单独复制；图片命中框贴合图片，用户图右对齐、Agent 图左对齐。
- 修复队列用户输入可见性、自动续接重复响应保护、运行中上下文与缓存命中展示。
- PC/移动端内置浏览器接管弹出新页，并保留刷新能力。
- PC Build Block 展开严格移除玻璃、白板底色、圆角与阴影。

## 发布边界

- Windows 资产未做 Authenticode 签名，本版本保持 prerelease。
- Android APK 使用工程既有 Android Debug 证书并通过 APK Signature Scheme v2 验证，不属于应用商店正式签名。
- macOS DMG 需要 macOS 构建主机，不在本次 Windows/Linux/Android 六资产矩阵内。
