# dev-0.1.7 Conversation Branch Tree Stability

Date: 2026-07-25

## Outcome

Conversation branching now uses a version 2 tree with stable message, Guide, Build, branch-node, and full branch-path identities. Editing is resolved against the complete viewed branch path rather than the runtime active node or a rendered message index. Each persisted conversation tree includes a rebuildable full node index directory with parent/child links, root-to-node paths, page groups, message IDs, Guide IDs, Build IDs, and running Build IDs.

Guide editing clones the owning Build prefix with a new `runId`, reparents copied events and earlier Guides to that Build, and continues only on the new branch. The original Build and later Guide content remain isolated on the original page. Read-only page inspection persists the viewed path without switching or stopping the runtime branch.

- Historical baseline `b85b6d2` compiled successfully but failed `conversation-branch-regression-canary.cjs` because it did not expose the full branch index directory and could not satisfy viewed-path ownership.
