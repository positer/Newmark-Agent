# dev-0.1.9 Memory Lab Tag Motion Damping

## Scope

- Advance desktop source development from `0.1.8` to `0.1.9`.
- Slow Memory Lab overview tag motion after user feedback that the graph moved too quickly.
- Preserve graph forces, relationship spacing, ambient motion, focus, camera, and drag behavior.
- Stop incidental overview reloads and improve zoom/drag responsiveness.

## Implementation

- Changed the per-step velocity retention from `0.86` to `0.72` for both axes.
- This increases per-step velocity damping from 14% to 28% without changing the force model.
- Named the retention parameter at the integration site so the motion tuning is explicit and auditable.
- Added a source regression assertion for the exact retention value and both velocity integration paths.
- Reuse the live graph when the tag/component topology signature has not changed, preserving node positions across incidental panel renders.
- Route overview tag/search selection to the live focus path instead of rebuilding the panel.
- Make Reset update the current camera in place.
- Render wheel zoom immediately around the pointer with a gentler exponential curve and without advancing the force simulation in the interaction frame.
- Apply drag transforms synchronously on pointer movement and remove delayed edge auto-pan drift.
