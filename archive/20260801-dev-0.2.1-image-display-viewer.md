# dev-0.2.1 image display and viewer

Date: 2026-08-01

## Scope

- Add an Agent-callable image display tool.
- Embed displayed images immediately after their GUI Build tool call.
- Preserve ordered images at the start of collapsed Build summaries.
- Add interactive TUI `示意图` rows and Enter-to-open behavior.
- Make Memory Lab Overview a real graph-only viewer entry in TUI.

## Implementation

- Added `image_display(path, caption?)` as a protected mode-scoped tool.
- Added strict workspace containment, PNG/JPEG decode validation, 10 MiB bounds, SHA-256 content addressing and restart hydration.
- Extended public Work Events with a dedicated display-image reference; disk state omits base64 bytes.
- GUI tool-result reconciliation attaches the image to the matching call; expanded and collapsed render paths share one validated renderer.
- TUI history focus traverses Build headers and image rows. Enter on a row opens a one-purpose Electron viewer.
- Added an explicit `--newmark-viewer` Electron mode. One-use viewer requests stay below the runtime root and the mode loads no main Newmark UI.
- Memory Lab `Overview · 示意图` opens only a bounded SVG overview derived from its visualization snapshot.
