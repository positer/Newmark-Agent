# dev-0.2.5 release (2026-08-03)

## Feature: SubAgent work streams live into GUI and TUI

- GUI: new SubAgent work overlay (draggable panel on the subagents surface) renders task lifecycle, streamed text, tool calls/results, and completion per peer; caches up to 500 events per actor; reopening a finished SubAgent replays its work from cache; Esc / chat-tab close; zh UI text; public tool labels.
- TUI: Agents view expands each SubAgent row (Enter) into its conversation history and final result; second Enter collapses.
- Core: peer work events (`emitPeerWorkEvent`/`runSubagentJob` in `DESKTOP/src/core/agent.ts`) strip runtime/workspace keys and attach actor ids; `DESKTOP/src/core/conversationKernel.ts` broadcasts peer events without persisting them; `runtime.unsubscribePeer()` stops delivery.
- Tool surface: subagent orchestration core (`task` + `subagent_*`) is always preloaded by `routeToolSurface`/`ToolProvisionSession.reconcile` in `DESKTOP/src/core/agentKernelRunner.ts`, appended after the 8-schema intent slice; broker-equivalent surfaces (skill + core + broker) keep internal provision preface suppression.
