# Newmark Agent dev-0.5.11

## Highlights

- Mobile provider/model settings use unified single-line liquid-glass capsules, complete lift/move/drop flights, axis arbitration, bounded device actions, and corrected button hit regions.
- Mobile chat supports PC-compatible `image_display`; user images render above right-aligned user text, while Agent images render left-aligned with Agent text.
- Chat bottom avoidance now tracks the live Goal/Flow/Queue overlay height during size changes. Markdown and LaTeX preview reuse the conversation text safe insets on narrow screens.
- PC startup shows a lightweight shell before the hydrated UI and prepares lifecycle markers asynchronously, keeping the installed process responsive during startup.

## Verification

- Desktop and Android version checks: 0.5.11; Android versionCode 511.
- Android: 220 JVM tests, Vital Lint, R8 and isolated Release assembly passed.
- Windows MSI/ZIP and Linux AppImage/deb/unpacked ZIP passed the previously recorded packaged black-box gates.
- This Windows-hosted release contains six assets: Windows x64 MSI/ZIP, Linux x64 AppImage/deb/ZIP, and Android APK.

## Signing and platform boundaries

- Windows MSI is not Authenticode-signed.
- Android APK uses the project Android Debug v2 certificate, not a store production keystore.
- macOS DMG is not included because it must be built and signed on a macOS host.
- No Android device was connected for final on-device visual acceptance.
