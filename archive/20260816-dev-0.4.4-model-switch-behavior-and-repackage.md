## 改动 review（同事）

1. **`agent:setModel` 语义修正**（main.ts）：比较切换前后的 `modelSelectionValue()`（qualified deployment 或 auto）而非裸模型名，避免两个 provider 上的同名模型切换被误判为"无变化"（否则跳过上下文压缩/内核重置）。
2. **运行时 pending 传播**（conversationKernel.ts / electronUtilityRuntimePool.ts / electronUtilityAgentClient.ts / wslAgentRuntimePool.ts / wslAgentClient.ts / utilityAgentProtocol.ts / wslAgentProtocol.ts / conversation-utility-host.ts / wsl-agent-host.ts）：`ConversationKernel.setModel` 在 Build 块运行中记录 pending 选择（`runtime.options.model`），下次 Guide/Next dequeue 时 `syncPendingModel` 仅在确实变化时切换；Electron/WSL 两套 utility 池、客户端、host 全链路补 `set_model` 方法。
3. **上下文窗口解析**（agent.ts `resolveWindowModel`）：auto/当前选择经 `activeModelConfig()` 解析 qualified deployment，同名校跨 provider 不再回退 128000 默认窗口。
4. **GUI 即时刷新**（index.html）：模型切换后立即拉取新 `contextWindow` 并重绘上下文环/检查器，不等待下一次 send。
5. **测试**：`verify.ts` 新增同名校跨 provider 上下文窗口断言（32k vs 96k）；新增 `modelSwitchBehaviorVerify.ts` 挂入 `test:desktop:built`。

review 结论：改动自洽、全链路配套齐全、typecheck 通过、无安全隐患。
