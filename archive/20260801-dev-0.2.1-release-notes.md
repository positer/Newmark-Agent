# Newmark Agent dev-0.2.1

This prerelease unifies the updated GUI/TUI conversation experience and introduces first-class Agent-displayed images.

## Highlights

- Added Agent-callable `image_display` for workspace PNG/JPEG evidence.
- GUI images appear immediately after their tool call and remain ordered at the start of collapsed Build summaries.
- TUI rows show only `[示意图]` until selected, then reveal the vision-derived image title and `Enter 打开`.
- Image Enter opens an isolated viewer titled with the image title; Memory Lab Overview opens a graph-only isolated viewer.
- Added live Memory Lab tag search, current-model display beside the Conversation title, placeholder removal, render coalescing, duplicate-frame suppression, and capped animation cadence.
- Added explicit global/npm `Newmark --GUI`; `Newmark --TUI` remains available.
- Optimized Browser Use from the official Crawl4AI readiness/extraction design: adaptive DOM-stability waits, main-content-first observation, bounded text walking, and cached visibility checks while preserving opaque refs and fixed host scripts.
- Added determinate per-model validation progress; every completed, cached, unsupported, or skipped check advances the visible progress bar.
- Fixed Guide/Next restart durability by preventing stale workspace `config.json` values from overriding the user-level mode.
- Standardized intelligence as `low`, `medium`, `high`, `xhigh`, and `max`, moved the shared control into TUI Model and GUI Models, and applied it to real Chat Completions/Responses reasoning requests.

## Validation

- 120-image/240-update packaged GUI stress preserved exact expanded/collapsed order at 2.90 ms P95 update time.
- 30-window image/Memory Lab viewer burst: zero failures, peak 6 concurrent viewers, 1581.5 ms startup P95.
- Full source gate passed with TUI 53/53, launcher 19/19, real OpenSSH/WSL PTY gates, 502 captured intelligence requests, and GUI/TUI/CLI shared-backend stress.
- Windows MSI/ZIP and Linux AppImage/DEB/unpacked ZIP asset smokes passed.
- Final Windows MSI package smoke passed at version 0.2.1.0; machine-wide installation completed, the installed payload matches the package, and existing user configuration was unchanged.
- Linux GUI Bash/sh round trips and relaunch/exit lifecycle passed under Xvfb.
