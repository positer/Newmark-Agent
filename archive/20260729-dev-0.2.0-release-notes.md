# Newmark Agent dev-0.2.0

`dev-0.2.0` adds a real terminal interface that shares Newmark's existing workspace, conversation, configuration, model/provider, Memory Lab, and Core runtime state with the desktop GUI and CLI.

## Highlights

- Start from any folder with `Newmark --TUI`; that folder is selected or registered as the Workspace.
- Navigate menu levels horizontally and entries vertically, expand or collapse Workspaces with Enter, and enter Conversation editing directly.
- Keep active Conversations running while changing focus, with a rotating sidebar marker and the existing two-stage Esc stop behavior.
- Track Conversation-specific Plan, Goal, Subagents, Model, Flow Bar, Flow List, and Flow Task entries only when the corresponding state exists.
- Use Tab to return from editing to Conversation selection, Shift+Tab to change work mode, and mandatory workflow selection when entering Flow.
- Pin Conversations with T, open complete shortcut guidance from Operations > Help, and use complete dark or light terminal canvases.
- Open Memory Lab Detail and edit the same provider/model settings used by the desktop application.

## Integration and packaging

- The TUI delegates to the existing Agent, WorkspaceManager, MemoryLabManager, AutomationManager, configuration, and persistence implementations.
- GUI, TUI, and CLI share mutable state under `~/.Newmark`; installation directories remain immutable.
- The Windows MSI carries both `Newmark Agent.exe` for the GUI and console-subsystem `Newmark.exe` for terminal use, and registers the install directory on the user PATH.
